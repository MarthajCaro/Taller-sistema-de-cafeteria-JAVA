# Taller Sistema de Cafetería - Java

## Descripción
Este proyecto contiene la solución del taller de Java enfocado en lógica de programación y simulación de un sistema de cafetería.

---

##  Ejercicio 1 — Variables y tipos de dato

### Explicación
Se declararon variables para representar un producto de la cafetería, incluyendo nombre, precio, cantidad en inventario, disponibilidad y código.

### Respuesta
Usamos el tipo de dato double para el precio porque permite representar valores con decimales, lo cual es necesario en precios como 3.50. Si utilizáramos int, solo podríamos almacenar números enteros, por lo que al asignar un valor como 3.50 se produciría un error o se perdería la parte decimal. Esto generaría imprecisiones en los cálculos financieros, lo cual es crítico en un sistema de ventas.
